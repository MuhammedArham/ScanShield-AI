# trustparty

Direction: white canvas, near-black text, restrained primary-colour accents. One primary action: choose a trusted person. Six dots are the brand graphic; no stock illustration, gradients, hero cards, testimonials, or promotional eyebrow copy.

Palette: ink #111111; white #ffffff; blue #1648e8; red #e73527 (decorative only); yellow #ffda24 with black text. Normal text pairs measure at least 4.5:1. Sans-serif typography, short readable measures, 52px primary controls, visible keyboard focus, native dialog and disclosure controls, reduced-motion support.

User reference: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
Read .claude/skills/ui-ux-pro-max/SKILL.md and quick-reference.md. Design-system search was partly off-topic (academic serif, dark palette, testimonials); those recommendations were rejected. A narrower `Bauhaus primary geometric --domain style` search returned the active Bauhaus style. Applied its geometric primary colours and clear hierarchy, adapted to a restrained responsive web page. User instructions take precedence over the database.

Sample-call functionality is removed. Setup retains manual fields, supported contact picker, review, explicit acknowledgement, and an honest prototype completion screen. Contact details are ephemeral and cleared at completion or dialog close; no server transport, persistence, calls, or invitation delivery.
