STAGE 05A

Deterministic rules

Explicit unsafe requests produce immediate advisory warnings. The rules also inspect preceding context for narrow references to a previously named tool or payment.

OTP/password disclosure → critical. Supported remote-access or urgent payment requests → high. Harmless mentions and negated requests have counterexamples.

04 / FAILURE BEHAVIOUR
Degradation stays visible.
Provider fails
Timeouts, invalid JSON or invented evidence degrade provider health. Existing warnings remain active.
Input is incomplete
Gaps, conflicting finals and capacity rejection are observable. A successful model response does not clear input-gap health.
The call ends
Return the final snapshot, cancel provider work and release state. Late responses cannot revive the ended call.

    
05 / BOUNDED STATE
Memory has explicit limits.
32ACTIVE CALLS
40RECENT TURNS / CALL
40UNASSESSED TURNS / CALL
100EVIDENCE SEGMENTS / CALL
Additional per-call bounds: 1,000 distinct segment IDs and 4,000 delivery events. Accepted unassessed turns are retained; exhaustion is rejected visibly. No database or raw-audio storage.
