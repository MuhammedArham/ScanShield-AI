# Repository instructions

## Agent skills

### Issue tracker

Track specs and tickets as local Markdown under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage statuses. See `docs/agents/triage-labels.md`.

### Domain docs

Use one root `GLOSSARY.md` and `docs/adr/`, created as terms and decisions are resolved. See `docs/agents/domain.md`.
